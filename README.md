# POS Harpa · Punto de venta

Punto de venta SaaS de **[Harpa SpA](https://harpa.cl)** con boleta y factura electrónica integradas con el SII. Nació como módulo del [Sistema de Gestión Avícola](https://github.com/HaxPG/harpa-sistema-avicola) y hoy es un producto independiente, conectado al [SGI](https://github.com/HaxPG/harpa-sgi) de Harpa para la gestión de planes.

> **El código fuente es privado** y pertenece a [Harpa SpA](https://github.com/Harpa-SpA). Este repositorio solo presenta el proyecto. Si quieres conocer más detalles técnicos o ver una demo, escríbeme por [LinkedIn](https://www.linkedin.com/in/nain-burgos-ortiz-b96b35260) o en [harpa.cl/contacto](https://harpa.cl/contacto).

## Qué hace

- Cajas, ventas, pedidos y cotizaciones.
- Boleta y factura electrónica (DTE) con el SII: firma, folios (CAF) y verificación previa al envío.
- Modo terminal para operar en el mostrador.
- Planes y límites sincronizados con el SGI.

## Tecnologías

- **Frontend:** Angular 20, Tailwind CSS, Nginx
- **Backend:** Node.js, Express, TypeScript, MySQL 8.4, autenticación JWT
- **Facturación electrónica:** herramientas en Python para firma, CAF y verificación de DTE
- **Infraestructura:** Docker, Docker Compose, GitHub Actions
